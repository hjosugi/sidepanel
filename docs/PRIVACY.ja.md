# プライバシーポリシー

Sidepanel Bookmarks は、ブックマークを Chrome のサイドパネルに表示し、選んだページをサイドパネル内で開く拡張機能です。

最終更新日 2026-11-28

## 扱うデータ

次のデータをブラウザ内でのみ扱います。

- ブックマーク: ツリー表示と検索のため
- パネルと同じウィンドウの HTTP・HTTPS タブの URL とタイトルを、一覧の表示・絞り込みと、利用者が現在のタブをパネルで開く操作に使います
- サイドパネルで開いたページの URL とタイトル: ヘッダーとタブ列に表示するため。最後に開いた URL は次回の復元用に保存します
- サイドパネルで開いたサイトの Cookie（後述）
- サイドパネル内のフレームの応答ヘッダー: エラーの検知と、埋め込みを禁止しているネストしたフレームの除去のため
- 設定: 言語、モバイル表示、保持するページ数、ズーム（既定とサイトごとの倍率）、パネルを開いたときの表示、ピン留めしたサイト（URL と名前）、デスクトップ表示にするサイト、通常のタブと同じ表示にするサイト

## ローカルでの処理

ブックマークや開いているタブの絞り込みは端末内で行います。解析や広告はありません。アドレス欄でウェブ検索を確定したとき、または一覧で「Bing で検索」を選んだときに、検索語を Microsoft Bing に直接送ります。どちらの欄も入力中の検索語は送信しません。

サイドパネルで開いたページは、通常のタブと同じくそれぞれのサイトから直接読み込まれ、そのサイトのプライバシーポリシーに従います。

## Cookie

通常のタブと同じようにログインが使えるよう、サイドパネルで開いたページには、そのサイト自身の非 HttpOnly Cookie を `document.cookie` で渡します。HttpOnly Cookie と他のサイトの Cookie は渡しません。ページが書き込めるのは自分のサイトの Cookie だけです。

## 通信の変更

サイドパネルを開いている間だけ、サイドパネル内のフレームに限って、埋め込みを禁止する `X-Frame-Options` と CSP ヘッダーの除去、`Sec-Fetch-Dest` / `Sec-Fetch-Site` の書き換え、（設定で無効にしていなければ）モバイルの User-Agent の送信を行います。通常のタブには影響せず、最後のサイドパネルを閉じるとこれらのルールは削除されます。

## 保存

設定は `chrome.storage.local` に、フォルダの開閉状態と最後に開いたページは拡張の `localStorage` に保存します。通常のタブと同じ表示にするサイト（既定は Claude）では、そのサイトのスクリプト中のフレーム判定の位置を、スクリプトを読み直さずに済むよう、そのサイトの `localStorage` の `spb:unframe` に覚えます。同期やアップロードはしません。

## リモートコード

リモートの JavaScript や WebAssembly は読み込みません。実行するコードはすべて拡張に同梱されています。

## データの共有

開発者は利用者のデータを収集・販売・譲渡せず、拡張の単一の目的と関係のない用途に使いません。信用力の判断や融資の目的にも使いません。
