# Sidepanel Bookmarks

Edge のサイドバーのように、Chrome のサイドパネルにブックマークを並べ、クリックしたページを**そのままサイドパネル内で開く**拡張機能です。依存ゼロ・ビルド不要で、軽く動くことを優先しています。

## 機能

- ツールバーのアイコンでサイドパネルを開閉
- ブックマークをフォルダツリーで表示（開閉状態を記憶）
- 検索（Enter で先頭の結果を開く）
- クリックでサイドパネル内に表示。Ctrl / Shift / 中クリックは通常どおりタブ・ウィンドウで開く
- ツールバー：☰ 一覧 / ‹ › 戻る・進む / ⟳ 再読み込み / ↗ 表示中のページをタブで開く
- 前回開いていたページを次回も復元
- ブックマークの追加・削除・並べ替えは自動で反映

## インストール

1. [Releases](https://github.com/hjosugi/sidepanel/releases) から zip をダウンロードして展開（または `git clone`）
2. `chrome://extensions` を開き、右上の「デベロッパー モード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選択
4. ツールバーにピン留めしたアイコンをクリック

Chrome 128 以降が必要です（Brave など Chromium 系ブラウザでも動作します）。

## 軽量化の工夫

- 素の HTML / CSS / JS のみ（フレームワーク・ビルドなし、合計 11KB 程度）
- バックグラウンドはインストール時に 1 回設定するだけで、常駐処理なし
- フォルダの中身は開いたときに初めて読み込む。ファビコンは遅延読み込み
- クリック処理はイベント委譲で 1 つだけ。表示用の iframe も 1 つだけ

## 仕組みと権限

多くのサイトは `X-Frame-Options` や CSP の `frame-ancestors` で iframe への埋め込みを禁止しています。この拡張は declarativeNetRequest のセッションルールで、**タブに属さないリクエスト（＝サイドパネル内の iframe）に限って**これらのヘッダーを取り除きます。通常のタブで開いたページには影響しません。

| 権限 | 用途 |
| --- | --- |
| `sidePanel` | サイドパネルの表示 |
| `bookmarks` | ブックマークの読み取り |
| `favicon` | サイトアイコンの表示 |
| `declarativeNetRequestWithHostAccess` + `<all_urls>` | サイドパネル内でだけ埋め込み禁止ヘッダーを外す |
| `webRequest` | iframe 内で移動した先の URL を知る（読み取りのみ。「タブで開く」用） |

## 制限

- Google のログイン画面など、iframe 内では動かないサイトがあります → ↗ でタブで開いてください
- CSP に `frame-ancestors` を含むサイトは、サイドパネル内では CSP ヘッダー全体が外れます（ヘッダーの一部だけを書き換えることができないため）
- ヘッダー部分のタイトル欄は URL を表示します（別オリジンのページタイトルは取得できないため）
- ブックマークレット（`javascript:`）は非対応。`chrome://` などのページはタブで開きます
